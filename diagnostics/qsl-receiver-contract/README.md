# QSL receiver contract diagnostic

A bounded standalone Java 21 diagnostic, staged for parent/publisher review. Preparation status: source integrity and Python syntax checked only; Java compilation and both suites have **not** run locally. Only the eventual exact-commit CI result can establish whether these contracts pass.

The unchanged three candidate classes and existing 24-case suite come from `work/network-api-receiver-next`. The new 10-scenario differential suite executes the original alpha.5 `GlobalReceiverRegistry.java` and `AbstractNetworkAddon.java`, copied byte-for-byte from the source archive pinned in `source-provenance.json`. Every operation compares return/exception type and global plus two-session state against the candidate, and checks a specified upstream expectation. Cases cover first-wins registration, dynamic propagation, local/global collisions, global removal of a same-ID local, absence of fallback/duplicate recopy, validation before mutation, absent unregister validation, stopped sessions, reserved IDs and null arguments.

Five deliberately tiny files under `test-doubles/` supply external Minecraft payload IDs/phase/side, reserved-name recognition, and payload-type presence lookup. The original abstract addon subclass has empty external hooks. It does not implement the receiver maps, locks, propagation or unregister behavior being tested. The candidate's supplied host hooks are also external fixtures. These doubles do not establish mapped Minecraft ABI, actual Minecraft IDs, codec registration/decoding, Netty threads, socket/wire behavior, native events, full lifecycle, loader integration, or gameplay. The existing 24-case candidate suite provides broader projection checks, not upstream-native equivalence. No claim is made for native QSL PLAY subclasses.

## Inputs and bounded execution

`dependency-lock.json` reuses existing exact URL, SHA-256 and size pins: Temurin JDK 21.0.12.1+1, fastutil 8.5.12, SLF4J API 2.0.9 and JetBrains annotations 24.0.1. Only those four inputs are downloaded in CI, under 232 MB total. Each response is size-bounded and SHA-256 verified before use; permitted HTTPS download/redirect hosts are explicit. The source archive is not downloaded during this job: only the two preserved source files are compiled. Apache-2.0 and project MIT licenses are included. Original headers remain intact; the differential harness and doubles are self-authored MIT.

`python3 diagnostics/qsl-receiver-contract/bootstrap.py check` is a source-only local preflight. `run` requires GitHub Actions, the exact repository, push event and literal diagnostic branch. The runner uses only standalone `javac --release 21 -proc:none` and `java`, a fresh run directory, and no Gradle, Minecraft JAR, mappings, assets, game launch, persistent cache, secrets, uploaded artifacts or binary/base64 log output. SLF4J may report that no logging provider is installed; the core test uses its official no-op fallback.

One `ubuntu-24.04` job has a hard 15-minute timeout and fixed concurrency group. Official checkout is SHA-pinned with persisted credentials disabled. There is no main, pull-request, fork, manual-dispatch or schedule trigger. The sole literal push branch is `diagnostic/qsl-receiver-contract-20261005-a`.
