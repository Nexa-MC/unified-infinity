# C1 source and pure owner contracts

These tests do not launch Minecraft, Gradle or a GUI. No network is used. Every JVM command is sequential, one active processor, at most 512 MiB heap, and must be run only while holding the parent-controlled single JVM slot. Test config/defaultconfig directories are fresh temporary directories below this directory's build path and removed when the run finishes.

- `static_checks.py`: frozen source/provenance/isolation/owner-boundary checks, Python only
- `boundary/test_boundary.py`: official classfile/member/closed-symbol proposal checks, Python only
- `run.py`: bounded javac then a pure Java contract harness using actual patched native IO owner sources and real pinned NightConfig 3.8.3
- `compile_official_inputs.py`: two bounded official-Forge-only javac calls for positive and negative external input
- `run_real_integrations.py`: actual-dependency compile, actual ASM transformer, real native final acceptEvent/event bus and OS watcher transitions with CodeSource/stub-absence assertions
- `run_native_baseline.py`: unmodified frozen owner comparison with and without acknowledged watch readiness
- `check_candidate_abi.py`: checks every proposed exact member descriptor against the compiled candidate facade classes, Python only
- `boundary/validate_compiled_probe.py`: checks independent official-Forge compiled positive and negative input classes, Python only

The harness covers initial defaults and comments, empty registration, default name, templates/correction, reload values and restart caches, correction backup bytes, set-autosave before explicit save, save from Loading without recursion, fresh tracker/spec reopen, malformed load/reload preserving bytes/cause, filename collision, pre-build/dev/production reads, true read-only native views, int/void composition, custom specs and unsupported types. Native spec controls test strict pre-load reads, restart cache retention, save-time Reloading and malformed recovery in the same JVM.

Stand-ins in `stubs/` deliberately replace loader bootstrap/container event dispatch and OS watcher scheduling; this isolates the config owner without initializing Minecraft or the full loader. Assertions on callback count mean one explicitly invoked owner callback, not one OS filesystem event. `reference/` contains unchanged pinned official Forge/NeoForge specs for semantic comparison. `official-input/` is the original self-authored probe compiled independently against official Forge binaries, never against the facade.

`build/run-001/` preserves the initial 104-assertion successful run's exact receipt, logs and tested-source ZIP. `build/run-002/` preserves the first 107-assertion coexistence run. `build/run-003-final/` preserves the final 107-assertion run plus paired synchronous-save failure comparison. `build/failure-order-before-fix/` preserves the original cache-order mismatch; the fix preserves WritingException and old cached4/raw6/persisted4 after injected failure, committing successful cache updates under the same native owner lock. `build/real-integrations/` preserves the final 21-assertion real-bus/OS-watcher run and actual ASM fixture acceptance/rejection; its attempt-001 directory retains the failed pre-readiness run, and attempt-002 retains the first passing acknowledgement run. `build/native-baseline/` shows that the unmodified frozen native owner missed the first write before registration acknowledgement and observed it after acknowledgement. The deeper test adds no watcher: a no-op removeWatchFuture for an unwatched sibling acknowledges the same filesystem control queue before mutation. No exact OS notification count is asserted. These source/pure-JVM tests still do not establish a game result, host constructor/lifecycle ordering, assembled runtime acceptance or production ledger admission.
